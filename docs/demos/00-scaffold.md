# Demo — Slice 0: Scaffold

1. `npm install`
2. `npm run dev` (runs `tauri dev`; first build takes a few minutes)
3. A window titled **Local IDP** opens and shows **pong** under the heading.
4. `app/src/bindings.ts` is regenerated on each debug run; `git status` shows no diff.
5. Open devtools (right-click → Inspect) → Console: no CSP violations.
